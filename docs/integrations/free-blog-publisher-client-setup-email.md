Subject: One-time setup for your blog publisher

Hi Lisa,

The free blog publisher is ready for its one-time account connection. Once connected, you will have a private, password-protected page where you can enter the blog title and copy, choose a topic, add the featured image and image description, and set the planned publication date and time.

When you publish, the website will automatically create the full article page and update its search information, social sharing image, XML sitemap, main Blog page, matching topic page, homepage Latest from the Blog section, and card preview text.

Please complete these steps:

1. Create or sign in to a free Cloudflare account at https://dash.cloudflare.com/. Open Workers & Pages once and create the free `workers.dev` address if Cloudflare prompts you to do so.
2. Send me an invitation to the Cloudflare account so I can deploy the private publisher. In Cloudflare, open Manage Account, choose Members, and invite me with permission to edit Workers scripts. I will provide the email address to use separately.
3. Choose the password you want to use for the publisher. We will enter it directly into Cloudflare as an encrypted secret rather than storing it in the website or GitHub. Please do not send the password by email or text; we can enter it together during setup.

I will handle the private GitHub connection from the repository owner's account. You do not need to create or send a GitHub token.

The free version requires one manual step at publication time: prepare the post in advance and save it as a draft, then return at the planned time and click Publish Now. The website usually updates within a few minutes. Automatic unattended publishing at an exact time can be added later if that becomes useful.

Featured images should be JPG, PNG, or WebP files no larger than 1 MB. Landscape images will display best across the article, homepage, and Blog cards.

Once the Cloudflare invitation is sent, I can complete the deployment and give you the private publisher link.
